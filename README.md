## 🚀 开始使用

### ① 先装一个油猴

在浏览器里安装 **[Tampermonkey（篡改猴）](https://www.tampermonkey.net/)**。

- **电脑**：使用支持油猴扩展的 Chrome、Edge 或 Firefox。
- **安卓手机／平板**：需要使用能够安装脚本扩展的浏览器。已有三星平板 Edge 用户实测成功，也可尝试 Firefox。
- **Mac**：可以使用支持油猴的浏览器；目前仍欢迎补充实测反馈，Safari 尚未验证。

安卓浏览器是否能安装油猴，取决于具体版本；仅打开“桌面版网站”不会增加扩展支持。

### ② 添加脚本

1. 打开本仓库中的 **[脚本文件](./bilibili-web-ip.user.js)**，复制完整代码。
2. 打开油猴控制面板，选择 **“添加新脚本”**。
3. 删除编辑器里的模板，粘贴代码，保存并启用。

也可以下载本仓库的 **[安装向导](./安装向导.html)**，在浏览器中打开，点击“复制完整脚本”。

### ③ 打开 B 站

重新打开一个 B 站页面，等待页面加载完成。右下角出现 **“IP 属地”** 按钮，就可以查看设置和运行状态了。

平板建议开启浏览器菜单里的 **“桌面版网站”**。

## 🔓 第一次使用
<img width="2534" height="1596" alt="图片" src="https://github.com/user-attachments/assets/a1fce5b6-6066-4798-a13d-cb3a47ba4529" />

**看评论属地，不需要额外授权。** 脚本会尽量直接读取页面已有的信息。

想看到 **个人主页、当前 UP 主、首页和右侧推荐** 的账号属地，再完成下面这一步：

> 登录 B 站 → 点击右下角 **IP 属地** → 阅读并勾选说明 → 点击 **授权读取账号属地**。

如果油猴弹出域名访问提示，允许脚本访问对应的 B 站接口即可。完成后，属地会陆续显示，不需要每次打开视频都重新授权。

<details>
<summary><b>授权安全吗？会不会过期？</b></summary>

这是 B 站的客户端登录凭证，不是专门的“属地只读权限”。本脚本只用它向 B 站查询公开的账号属地，凭证保存在当前油猴中，不发送给第三方，也不输出到日志。

凭证可能失效。当前版本不会自动续期，也不显示准确到期时间；遇到鉴权错误时，再根据面板提示重新授权即可。非官方授权流程也可能因 B 站调整而失效，或使网页需要重新登录。

“清除授权”会清除脚本本机保存的凭证；如需撤销 B 站服务端登录凭证，需要在 B 站账号设备管理中处理。

请勿分享你的 Cookie、授权凭证或包含这些内容的油猴备份。

</details>

## 💡 常见问题
<details>
<summary><b>为什么有些账号显示“未知”？</b></summary>

| 显示内容 | 意思 |
| --- | --- |
| `IP：广东` | 已取得属地 |
| `IP：未知` | 查询成功，但 B 站没有提供地区 |
| `IP：无法获取` | 本次请求失败，详细提示会保留实际错误 |
| `IP：未授权` | 还没有完成账号属地授权 |
| `IP：待查询` / `IP：查询中` | 尚未取得结果，可能正在排队或需要追加额度 |
| `IP：暂缓查询` | 遇到接口限制，暂时停止新查询 |

**没有属地，不等于账号被封禁或长期未登录。** 无法确定的原因，脚本不会猜测。
</details>
<details>
<summary><b>为什么往下翻，有些推荐没有马上显示 IP？</b></summary>


为了减少流量和请求次数，脚本只查询 **进入屏幕的卡片**，并排队处理。

默认每个页面给 **20 位不同 UP 主**分配额外查询额度。同一个人出现多次不会重复计算，已缓存的属地也不占新额度，所以 **不是最多只能显示 20 个 IP**。

继续滚动不会自动重置额度。需要更多时，打开右下角面板，点击 **“追加 20 个卡片查询名额”**。评论、个人空间主人和当前视频 UP 主不受这个卡片额度限制。
</details>
<details>
<summary><b>会不会很费流量？</b></summary>

评论和动态尽量复用页面已有的数据。账号属地需要额外查询，但同一个账号会缓存 **24 小时**；查询成功但没有地区的结果缓存 **30 分钟**。

账号接口可能返回一百多 KB 的未压缩文字数据，因此脚本设置了限速和卡片查询额度。你可以在面板查看本页额外请求次数及收到的数据大小，也可以暂停首页／推荐 IP。面板数字不等于完整的网络计费流量。

脚本不会在后台逐个打开用户主页，也不会为了查询属地加载对方的图片和视频。
</details>

<details>
<summary><b>评论没有属地，或者页面加载异常怎么办？</b></summary>

- 2022 年年中之前的历史评论可能本来就没有属地数据。
- 不同版本的评论组件或移动页面，可能还没有完全适配。
- 标签会在网页加载完成后稍晚出现，刚打开时可以等一会儿。
- 如果封面、头像或评论区加载异常，请暂时停用脚本，关闭页面后重新打开，比较是否恢复。

反馈时附上 **视频网址、设备和浏览器版本、脚本版本、问题截图**，以及“停用后是否恢复”，会更容易定位问题。截图记得遮住个人信息，不要提交登录凭证。

</details>

## ♻️ 已经安装过？

编辑油猴中原来的脚本，用新版代码完整替换并保存，**关闭旧页面再重新打开**。保留同一个脚本通常可以沿用原授权和缓存。

请只启用一份属地助手，避免与其他同类脚本重复显示。
